# Core Protocols & Fingerprinting Reference

Foundational abstractions and utilities underpinning the pipeline: phase runner protocols, recursive
component discovery/fingerprinting, run fingerprint functions, and the artifact dependency graph used for
cross-run invalidation diffing.
